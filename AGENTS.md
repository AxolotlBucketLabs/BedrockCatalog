# Agent instructions

Use the [AxolotlBucketLabs skill](https://github.com/AxolotlBucketLabs/axolotl-bucket-labs/blob/main/SKILL.md) for work on this project. Read its [writing style](https://github.com/AxolotlBucketLabs/axolotl-bucket-labs/blob/main/references/writing-style.md) before writing human-facing prose.

Write naturally, directly, and concisely. Use complete sentences and concrete facts. Do not use em dashes, en dashes, or semicolons in prose. Avoid unnecessary label-shaped sentences. Use Markdown inline code for technical names, paths, commands, versions, and manifest keys.

Keep credentials out of source files, logs, generated data, and commits. Do not claim a PlayFab operation works unless it has been verified against the Minecraft title.
